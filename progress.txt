## Codebase Patterns
- Static HTML project: No build system, TypeScript, or test framework
- All JavaScript is inline in index.html within <script> tags
- Uses localStorage for client-side persistence
- OpenAI API key stored in localStorage under 'openai-api-key'
- Projects stored in localStorage under 'opn-projects' as JSON array
- CSS is inline in <style> tags within <head>
- UI follows dark theme with colors #0d1217 (bg), #161d29 (sections), #355070 (buttons)
- Upload button selector: document.querySelector('.section button.button')
- To validate JS syntax: node -e "new Function(scriptContent)"
